# Taktile

> Taktile is an agentic decision platform for financial institutions that combines AI speed with human oversight to automate and optimize high-stakes decisions across banking and insurance. Its Decision Engine, AI Agent Manager, Case Manager, and Context Layer power onboarding/KYC, credit underwriting, AML and fraud investigation, claims processing, and insurance underwriting. The public product API surface (the Taktile API and Flow API) is documented on GitBook behind an authentication wall; this file is generated by the API Evangelist enrichment pipeline from public pages.
